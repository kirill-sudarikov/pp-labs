# Лабораторная работа №1. Последовательная реализация программы
## 1. Цель работы
Получить данные о работе последовательного алгоритма перемножения квадратных матриц для последующего сравнения с параллельными реализациями по технологиям OpenMP, MPI и CUDA.
## 2. Задачи
1. Написать программу на языке C++ для перемножения двух квадратных матриц.
2. Написать программу на языке Python для верификации результатов вычислений.
3. Провести ряд экспериментов с разными размерами входных матриц (200, 400, 800, 1200, 1600, 2000).
## 3. Ход работы
### 3.1 Реализация программы на C++
#### 3.1.1 Описание программы
Программа предназначена для перемножения двух квадратных матриц с элементами типа `double`. Исходные матрицы считываются из бинарных файлов, результат умножения записывается в бинарный файл. Также реализовано автоматическое создание квадратных матриц с псевдослучайными значениями в заданном диапазоне.

В процессе выполнения программа выводит порядок матриц, объём обрабатываемых данных, количество доступных логических процессоров и время выполнения операции умножения.

Для простоты хранения матриц и их использования в программе реализован шаблонный класс `square_matrix<T>`:
```cpp
export template <typename T>
class square_matrix final {
private:
  std::vector<T> _data;
  int _size{0};

public:
  square_matrix(const int n) : _data(n * n), _size(n) {}
...
};
```
В классе реализованы следующие методы:
1. Метод `size()` для получения порядка квадратной матрицы.
2. Перегрузки `operator[]` для чтения и доступа к элементам матрицы.
3. Метод `save_binary()` для записи матрицы в бинарный файл.
4. Метод `load_binary()` для чтения матрицы из бинарного файла.

#### 3.1.2 Алгоритм
Сам алгоритм перемножения реализован в виде отдельной шаблонной функции `multiply()`:
```cpp
export template <typename T>
void multiply(const square_matrix<T> &a, const square_matrix<T> &b,
              square_matrix<T> &res) {
  for (int i = 0; i < res.size(); ++i) {
    for (int j = 0; j < res.size(); ++j) {
      res[i, j] = row_x_col(a, i, b, j);
    }
  }
}
```
Перемножение строки на столбец вынесено в вспомогательную функцию `row_x_col()`:
```cpp
export template <typename T>
T row_x_col(const square_matrix<T> &a, const int ai, const square_matrix<T> &b,
            const int bj) {
  T res = T{0};

  for (int k = 0; k < a.size(); ++k) {
    res += a[ai, k] * b[k, bj];
  }

  return res;
}
```
В качестве типа элементов матриц выбран `double`. Для хранения крупных вещественных матриц используется собственный бинарный формат с расширением `.bin`. В файле последовательно сохраняются порядок квадратной матрицы $N$ и $N^2$ элементов типа `double` в построчном порядке.

Бинарное представление позволяет записывать значения `double` без преобразования в текстовый вид, уменьшает размер файлов и ускоряет операции чтения и записи по сравнению с текстовыми форматами (`.txt`, `.csv`). При текстовом представлении для точного восстановления значения `double` требуется достаточное число значащих цифр; при его недостатке возможна потеря точности при обратном преобразовании.

Также для автоматического заполнения матриц реализована функция `make_random_matrix()`, использующая генератор псевдослучайных чисел `std::mt19937` и равномерное распределение в заданном диапазоне.

#### 3.1.3 Запуск программы
Запуск программы осуществляется с помощью следующих команд:
Для генерации матрицы используется команда:

```text
lab-1 generate <size> <min> <max> <seed> <output.bin>
```

где:

- `<size>` — порядок квадратной матрицы;
- `<min>` и `<max>` — нижняя и верхняя границы диапазона случайных значений;
- `<seed>` — начальное значение генератора псевдослучайных чисел;
- `<output.bin>` — имя создаваемого бинарного файла.

Для перемножения двух матриц используется команда:

```text
lab-1 multiply <a.bin> <b.bin>
```

где `<a.bin>` и `<b.bin>` — бинарные файлы исходных матриц. Результат умножения сохраняется в файл `result.bin`.

### 3.2 Реализация программы на Python
#### 3.2.1 Описание программы
Программа на Python предназначена для автоматизированной верификации результата перемножения матриц, полученного программой на C++. Для выполнения проверки используется библиотека `NumPy`.

Скрипт считывает из бинарных файлов две исходные матрицы \(A\) и \(B\), а также результирующую матрицу \(C\), сформированную программой на C++. Размер матрицы считывается из заголовка каждого бинарного файла, после чего данные элементов типа `double` преобразуются в массив `NumPy` размерности \($N \times N$\).

Эталонный результат вычисляется средствами `NumPy`:

```python
np_r = a @ b
```

После этого матрица, полученная программой на C++, сравнивается с эталонной матрицей. Сравнение выполняется с заданной абсолютной и относительной погрешностью, что необходимо при работе с вещественными числами типа `double`.

Если результаты совпадают в пределах установленной погрешности, программа выводит сообщение:

```text
Verification passed: results match.
```

Если результаты различаются, выводится сообщение:

```text
Verification failed.
```

Также выводится максимальное абсолютное отклонение результата программы на C++ от эталонного результата, рассчитанного библиотекой `NumPy`.
#### 3.2.2 Запуск программы
Запуск программы верификации осуществляется из командной строки с указанием имён файлов двух исходных матриц и файла результата, сформированного программой на C++:

```text
python verify.py <a.bin> <b.bin> <result.bin>
```

где:

- `<a.bin>` — бинарный файл первой исходной матрицы;
- `<b.bin>` — бинарный файл второй исходной матрицы;
- `<result.bin>` — бинарный файл результирующей матрицы, полученной программой на C++.

Пример запуска программы:

```text
python verify.py a100.bin b100.bin result.bin
```

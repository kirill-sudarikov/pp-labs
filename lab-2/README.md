# Лабораторная работа №2. Параллельная реализация программы с помощью OpenMP
## 1. Цель работы
Получить экспериментальные данные о производительности алгоритма перемножения квадратных матриц, реализованного с использованием технологии параллельного программирования OpenMP. В дальнейшем эти результаты будут использованы для сравнительного анализа с последовательной версией алгоритма из [лабораторной работы №1](../lab-1/README.md) и с параллельными реализациями по технологиям MPI и CUDA.
## 2. Задачи
1. Модифицировать программу из л/р №1 для параллельной работы по технологии OpenMP.
2. Провести ряд экспериментов с разным количеством потоков (1, 2, 4, 8), разными размерами входных матриц (200, 400, 800, 1200, 1600, 2000).
## 3. Ход работы
### 3.1 Алгоритм
Основным изменением по сравнению с последовательной версией является добавление директивы `#pragma omp parallel for` перед внешним циклом. Это позволяет распределить итерации по строкам матрицы между доступными потоками процессора.
```cpp
export template <typename T>
void multiply(const square_matrix<T> &a, const square_matrix<T> &b,
              square_matrix<T> &res) {
#pragma omp parallel for
  for (int i = 0; i < res.size(); ++i) {
    for (int j = 0; j < res.size(); ++j) {
      res[i, j] = row_x_col(a, i, b, j);
    }
  }
}
```
Установка и проверка количества потоков вынесены за пределы функции перемножения матриц в `main.cpp`. Это позволяет сохранить исходную логику функции `multiply` неизменной.
```cpp
// Установка желаемого количества потоков
omp_set_num_threads(threads_count);

// Определение фактического количества запущенных потоков
#pragma omp parallel
#pragma omp single
    actual_threads = omp_get_num_threads();
```
### 3.2 Автоматизация сбора результатов
Для автоматизации процесса тестирования разработан скрипт `benchmark.py`. Он позволяет запустить всю серию тестов в автоматическом режиме, исключая необходимость ручного ввода команд в терминале и ускоряя сбор результатов.

**Краткое описание скрипта:**
* **Многопоточное тестирование:** Автоматически перебирает размеры матриц от `200x200` до `2000x2000` на `1, 2, 4 и 8` потоках.
* **Фильтрация аномалий (Медиана):** Каждый тест запускается **5 раз**. Чтобы исключить случайные задержки операционной системы (фоновые процессы, прерывания), скрипт высчитывает **медиану** времени выполнения.
* **Встроенная верификация:** После каждого перемножения скрипт автоматически вызывает `verify_result.py` для контроля корректности вычислений. Если параллельный алгоритм хоть раз посчитает матрицу неверно, это сразу отобразится в логе.
* **Экспорт данных:** Все данные (время каждой из 5 попыток, итоговая медиана и статус проверки) сохраняются в файл `benchmark_results.csv` с разделителем `;` для последующего анализа и построения графиков.

#### Запуск бенчмарка:
```bash
python lab-2/scripts/benchmark.py
```
*(Скрипт ожидает наличие скомпилированного исполняемого файла по пути `build/msvc-release/lab-2/lab-2.exe`)*

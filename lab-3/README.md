# Лабораторная работа №3. Параллельная реализация программы с помощью MPI
## 1. Цель работы
Получить экспериментальные данные о производительности алгоритма перемножения квадратных матриц, реализованного с использованием технологии параллельного программирования MPI (Message Passing Interface). В дальнейшем эти результаты будут использованы для сравнительного анализа с последовательной версией алгоритма из [лабораторной работы №1](../lab-1/README.md) и с параллельными реализациями по технологиям OpenMP и CUDA.

# Лабораторная работа №3. Параллельная реализация программы с помощью MPI

## 1. Цель работы
Получить экспериментальные данные о производительности алгоритма перемножения квадратных матриц, реализованного с использованием технологии параллельного программирования **MPI (Message Passing Interface)**. В дальнейшем эти результаты будут использованы для сравнительного анализа с последовательной версией алгоритма из [лабораторной работы №1](../lab-1/README.md) и с параллельными реализациями по технологиям OpenMP и CUDA.

## 2. Задачи
1. Модифицировать программу из л/р №1 для параллельной работы по технологии MPI.
2. Провести ряд экспериментов с разным количеством потоков (1, 2, 4, 8), разными размерами входных матриц (200, 400, 800, 1200, 1600, 2000).

## 3. Ход работы
### 3.1 Алгоритм
## Алгоритм

В MPI-версии сохранён алгоритм умножения матриц, но вычисление строк результирующей матрицы распределено между процессами. Основные изменения по сравнению с последовательной версией:
1. **Организация процессов.** Добавлены инициализация и завершение MPI, определение номера процесса и общего количества процессов.
```cpp
int main(int argc, char **argv) {
  MPI_Init(&argc, &argv); // инициализация MPI
  
    try {
      int rank, size;
      //...
      MPI_Comm_size(MPI_COMM_WORLD, &size); // определение общего числа процессов
      MPI_Comm_rank(MPI_COMM_WORLD, &rank); // определение номера процесса
    } catch (const std::exception &e) {
    //...
  }

  MPI_Finalize(); // завершение MPI
  return 0;
}
```
3. **Распределение данных.** Исходные матрицы загружает только процесс с рангом 0. Размер матриц и матрица $B$ передаются всем процессам с помощью `MPI_Bcast`, а строки матрицы $A$ распределяются через `MPI_Scatterv`. Если число строк не кратно числу процессов, первые процессы получают по одной дополнительной строке.
```cpp
int main(int argc, char **argv) {
  MPI_Init(&argc, &argv);
  
    try {
      //...
      if (rank == 0) { // нулевой процесс
        //...
        a.load_binary(a_filename); // загрузка матрицы A
        b.load_binary(b_filename); // загрузка матрицы B
  
        if (a.size() != b.size()) {
          std::cerr << "matrix dimensions must match" << std::endl;
          MPI_Abort(MPI_COMM_WORLD, 1);
        }
  
        n = a.size();
      }

      MPI_Bcast(&n, 1, MPI_INT, 0, MPI_COMM_WORLD); // рассылка размера матриц всем процессам

      local_n = n / size + (rank < n % size ? 1 : 0); // каждый процесс определяет для себя количество строк матрицы A

      //...

      MPI_Bcast(b_data, n * n, MPI_DOUBLE, 0, MPI_COMM_WORLD); // рассылка матрицы B всем узлам (процессам)

      MPI_Scatterv(a.data(), sendcounts.data(), displs.data(), MPI_DOUBLE,
                 local_a, local_n * n, MPI_DOUBLE, 0, MPI_COMM_WORLD); // распределение строк матрицы A между узлами
      //...
    } catch (const std::exception &e) {
    //...
  }

  MPI_Finalize();
  return 0;
}
```
5. **Параллельное вычисление.** Каждый процесс независимо вычисляет строки матрицы $C$, соответствующие полученным строкам $A$, используя полную копию $B$. Алгоритм вычисления элементов остаётся прежним.
6. **Сборка результата.** Вычисленные блоки строк объединяются на процессе с рангом 0 с помощью `MPI_Gatherv`, после чего итоговая матрица сохраняется в файл.
```cpp
int main(int argc, char **argv) {
  MPI_Init(&argc, &argv);
  
    try {
      //...
      MPI_Gatherv(local_c, local_n * n, MPI_DOUBLE, c_data.data(),
                sendcounts.data(), displs.data(), MPI_DOUBLE, 0,
                MPI_COMM_WORLD);
      //...
      if (rank == 0) {
        //...
        square_matrix<double> c(c_data, n);
        c.save_binary(c_filename);
    }

    } catch (const std::exception &e) {
    //...
  }

  MPI_Finalize();
  return 0;
}
```
8. **Измерение времени.** Вместо `std::chrono` используется `MPI_Wtime`. Отдельно измеряются время локальных вычислений и общее время участка с передачей данных и синхронизацией. Через `MPI_Reduce` с операцией `MPI_MAX` выбирается максимальное время среди процессов.
Таким образом, последовательное вычисление всей матрицы одним процессом заменено параллельным вычислением независимых блоков строк с последующей сборкой результата.
